# Coding Humanities & Computational Linguistics Coursework

Academic Python coursework, data structures, and text processing algorithms developed for Digital Humanities modules at Eberhard Karls Universität Tübingen (Winter Semester 2026/27).

## 📁 Structure & Modules
- **`01_data_structures/`**: Control flow demonstrations, age verification, selection sort, lists, sets, and tuples.
- **`02_nlp_and_text/`**: Text tokenization, frequency analysis, string normalization, and unit converters.
- **`03_algorithms_and_math/`**: Multiplication matrix formatting and algorithmic loops.
